# 📚 Student Attendance Management System – High-Fidelity UI Design

## ✨ Project Overview

This is a **Student Attendance Management System High-Fidelity UI Design** created using Figma. The application provides a modern and user-friendly interface for students, teachers, and administrators to manage, track, and monitor attendance efficiently.

## 🎯 Objective

The main objective of this project is to design an attractive and interactive attendance management application with a clean interface that makes attendance tracking simple, quick, and convenient.
